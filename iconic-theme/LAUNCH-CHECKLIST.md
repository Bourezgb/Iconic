# 🚀 ICONIC Theme - Launch Checklist

## ✅ مرحلة ما قبل الإطلاق

### 1. إعدادات البيئة
- [ ] WordPress 6.4+ مثبت
- [ ] PHP 8.0+ مفعل
- [ ] MySQL 5.7+ أو MariaDB 10.3+
- [ ] SSL/HTTPS مفعّل
- [ ] Permalinks مضبوطة على `/%postname%/`

### 2. الإضافات المطلوبة
#### أساسية (لا غنى عنها):
- [ ] **ACF Pro** - لإدارة الحقول المخصصة والإعلانات
- [ ] **Yoast SEO** أو **Rank Math** - للسيو المتقدم

#### اختيارية مستحسنة:
- [ ] **WP Rocket** أو **LiteSpeed Cache** - للكاش والأداء
- [ ] **Imagify** أو **ShortPixel** - لضغط الصور تلقائياً
- [ ] **Wordfence Security** - للأمان
- [ ] **UpdraftPlus** - للنسخ الاحتياطي

## 📋 إعدادات السيو (SEO)

### في Yoast/Rank Math:
- [ ] اضبط نوع المحتوى `post` كـ "Article"
- [ ] اضبط `interview` كـ "Interview"
- [ ] اضبط `video` كـ "VideoObject"
- [ ] فعّل Schema لكل CPT
- [ ] اضبط Breadcrumbs: `الرئيسية > %category% > %title%`
- [ ] فعّل Open Graph و Twitter Cards

### Slugs والتشغيل البيني:
- [ ] تأكد أن slugs هي:
  - `/interviews/` للمقابلات

  - `/profiles/` للشخصيات
  - `/special-features/` للملفات الخاصة
  - `/topic/` للأقسام
  - `/format/` لصيغ المحتوى

## ⚡ إعدادات الأداء والكاش

### WP Rocket / LiteSpeed:
- [ ] فعّل Cache للجوال والكمبيوتر
- [ ] فعّل Minify للـ CSS و JS
- [ ] فعّل Lazy Load للصور والفيديو
- [ ] استبعد `three-hero.js` من Minify إذا تسبّب مشاكل
- [ ] فعّل Delay JavaScript Execution
- [ ] اضبط Preload للروابط المهمة

### الصور:
- [ ] استخدم WebP/AVIF تلقائياً
- [ ] اضبط أبعاد الصور القصوى: 1920px للعريض، 800px للمقالات
- [ ] فعّل Responsive Images (`srcset`)

### الخطوط:
- [ ] حمّل خطوط Google Fonts محلياً
- [ ] استخدم `font-display: swap`
- [ ] حمّل فقط الأوزان المستخدمة (400, 600, 700)

## ✍️ كيفية إضافة المحتوى

### 1. إضافة مقال عادي:
- المقالات > أضف جديداً
- اختر **القسم الرئيسي** (ثقافة، سينما...)
- اختر **صيغة المحتوى** (خبر، تحليل، رأي...)
- اختر **المشروع** (اختياري: ICONIC TV...)
- عيّن الصورة البارزة (1920x1080)
- أضفsubtitle في حقل ACF المخصص
- حدّد "مدة القراءة" يدوياً أو دعها تحسب تلقائياً

### 2. إضافة تحليل أو رأي:
- اتبع الخطوات أعلاه
- اختر الصيغة: **تحليل** أو **رأي**
- سيظهر تلقائياً:
  - شارة ملونة أعلى العنوان
  - مقدمة بارزة
  - جدول محتوى (إذا كان طويلاً)
  - صندوق كاتب احترافي

### 3. إضافة مقابلة:
- مقابلات > أضف مقابلة جديدة
- النوع يُحدّد تلقائياً كـ `interview`
- أضف أسئلة وأجوبة باستخدام Gutenberg Blocks
- يمكن ربطها بشخصية أيقونية

### 4. إضافة فيديو:
- فيديو > أضف فيديو جديد
- ألصق رابط YouTube/Vimeo في الحقل المخصص
- أو ارفع الفيديو مباشرة (للأحجام الصغيرة)
- اختر المشروع (ICONIC TV, ICONIC MUSIC...)

### 5. إضافة ملف خاص:
- ملفات خاصة > أضف ملفاً جديداً
- يدعم التراتبية (صفحات فرعية)
- مثالي للسلاسل التحقيقية الطويلة

### 6. إضافة شخصية أيقونية:
- شخصيات أيقونية > أضف شخصية
- أضف السيرة الذاتية
- الصورة الشخصية
- ربط بالمقالات ذات الصلة

## 🏗️ كيفية إنشاء قسم جديد مستقبلاً

### عبر لوحة التحكم:
1. اذهب إلى **الأقسام والمجالات**
2. أضف قسماً جديداً (مثال: "فنون بصرية")
3. اختر أباً إن وجد (اختياري)
4. احفظ

### في الكود (للمطورين):
```php
// في functions.php أو plugin مخصص
wp_insert_term('فنون بصرية', 'topic', [
    'slug' => 'visual-arts',
    'description' => 'كل ما يتعلق بالفنون البصرية المعاصرة',
]);
```

### تحديث القائمة:
- المظهر > قوائم
- أضف القسم الجديد لـ **Primary Menu**
- optionally: أضفه لـ **Mega Menu**

## 🔧 قرارات تحريرية مطلوبة

قبل الإطلاق، يجب اتخاذ القرارات التالية:

1. **سياسة النشر:**
   - ما الحد الأدنى لطول "الملف الخاص"؟
   - هل نسمح بالتعليقات أم نعطّلها؟
   - ما سياسة التصحيح المعلنة؟

2. **الأولويات التحريرية:**
   - ما هي الأقسام الـ 3 الأساسية التي تظهر أولاً؟
   - هل هناك أقسام مؤجلة للإطلاق الثاني؟

3. **الفيديو:**
   - هل نستضيف الفيديو محلياً أم نعتمد على YouTube فقط؟
   - ما جودة الفيديو الافتراضية؟

4. **الإعلانات:**
   - ما نسبة المساحة الإعلانية المقبولة؟
   - هل نعرض إعلانات لطرف ثالث في المرحلة الأولى؟
