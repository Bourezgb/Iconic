## 🚀 طريقة التثبيت

### الطريقة 1: رفع الملف المضغوط
```bash
1. اذهب إلى لوحة تحكم ووردبريس
2. مظهر > قوالب > أضف جديد > رفع قالب
3. اختر ملف: iconic-theme-safe.tar.gz
4. فك الضغط ثم فعّل القالب
```

### الطريقة 2: عبر FTP
```bash
1. انسخ مجلد /workspace/iconic-theme 
   إلى /wp-content/themes/iconic-theme
2. فعّل القالب من مظهر > قوالب
```

## ⚙️ الإعدادات الأولية بعد التفعيل

### 1. إنشاء القوائم
- اذهب إلى **مظهر > قوائم**
- أنشئ قائمة جديدة باسم "Primary"
- أضف الصفحات والأقسام
- عيّنها كـ **Primary Menu**

### 2. ضبط الصفحة الرئيسية
- اذهب إلى **إعدادات > قراءة**
- اختر **صفحة ثابتة**
- حدد صفحة فارغة أو أنشئ صفحة جديدة
- سمّها "الرئيسية"

### 3. إضافة الشعار
- اذهب إلى **مظهر > تخصيص**
- هوية الموقع > رفع شعار
- أبعاد الشعار المقترحة: 200x80 بكسل

### 4. إضافة مقالات تجريبية
- اذهب إلى **مقالات > أضف جديد**
- أضف عنوان، محتوى، وصورة بارزة
- انشر 3-5 مقالات للتجربة

## 🔧 التطوير المستقبلي (آمن)

يمكنك الآن إضافة ميزات متقدمة تدريجياً عبر مجلد `inc/`:

```php
// في functions.php
iconic_include_safe('custom-post-types'); // آمن حتى لو الملف غير موجود
iconic_include_safe('acf-fields');        // يعمل فقط إذا كان ACF مفعل
iconic_include_safe('ad-manager');        // نظام الإعلانات
```

**الميزة:** إذا حذف ملف أو كان به خطأ، **لن ينهار الموقع**!
