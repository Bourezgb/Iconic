## 🚀 طريقة التثبيت (خطوة بخطوة)

### الطريقة 1: الرفع المباشر (الأسهل)

1. **حمّل الملف المضغوط:**
   - الملف جاهز في: `/workspace/iconic-safe-theme.tar.gz`

2. **ارفع إلى استضافتك:**
   ```bash
   # عبر FTP أو File Manager
   ارفع الملف إلى: /wp-content/themes/
   ```

3. **فك الضغط:**
   ```bash
   cd /wp-content/themes/
   tar -xzf iconic-safe-theme.tar.gz
   ```

4. **فعّل القالب:**
   - اذهب إلى لوحة تحكم ووردبريس
   - مظهر > قوالب
   - ابحث عن "ICONIC Safe Core"
   - اضغط "تفعيل"

### الطريقة 2: الرفع عبر لوحة التحكم

1. اضغط على **إضافة جديد** في صفحة القوالب
2. اضغط **رفع قالب**
3. اختر ملف `iconic-safe-theme.tar.gz`
4. اضغط **تنصيب الآن**
5. اضغط **تفعيل**

## 🔧 الخطوات التالية بعد التفعيل الناجح

1. **أنشئ القوائم:**
   - اذهب إلى مظهر > قوائم
   - أنشئ قائمة "الرئيسية" وعيّنها لـ "القائمة الرئيسية"
   - أضف روابط للأقسام

2. **اضبط الصفحة الرئيسية:**
   - اذهب إلى إعدادات > قراءة
   - اختر "آخر مقالاتك" كصفحة رئيسية

3. **أضف محتوى تجريبي:**
   - أضف 3-5 مقالات مع صور بارزة
   - شاهد كيف تظهر في الشبكة

4. **اختبر الموقع:**
   - تفقد الصفحة الرئيسية
   - افتح مقالاً
   - جرّب التنقل بين الصفحات

## ⚠️ إذا ظهر خطأ مرة أخرى

### 1. فعّل وضع التصحيح فوراً:

افتح ملف `wp-config.php` في جذر ووردبريس وأضف:

```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```

ثم تحقق من ملف `wp-content/debug.log`.

### 2. تحقق من صلاحيات الملفات:

```bash
chmod 755 /wp-content/themes/iconic-safe-theme/
chmod 644 /wp-content/themes/iconic-safe-theme/*.php
```

### 3. تأكد من عدم وجود قالب قديم:

```bash
rm -rf /wp-content/themes/iconic-theme/
rm -rf /wp-content/themes/iconic-safe-theme/
# ثم أعد الرفع من جديد
```
